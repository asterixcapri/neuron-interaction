# Input history

```php
use NeuronAI\Chat\Messages\UserMessage;
use NeuronInteraction\InputHistory\InputHistory;

$inputs = new InputHistory($storage);
$inputs->record(new UserMessage('/resume session-key'));
$inputs->record(new UserMessage('A message exactly as submitted'));
$submitted = $inputs->entries(); // Oldest first, across all Sessions.
```

Adapters record original submissions, including their Command invocation
syntax, and exclude prompts generated by Commands. Messages without visible
content are ignored; only consecutive exact duplicates collapse. Each read and append uses the
current Storage sequence, so existing instances see one another's submissions.
Simultaneous writes are not coordinated by this module; Adapters must serialize
them when sharing Storage across concurrent writers.

The same `InputHistory` instance optionally provides recall navigation:

```php
$recalled = $inputs->older(new UserMessage('Unsubmitted draft'));
$newer = $inputs->newer(); // Restores the draft past the newest input.
$navigating = $inputs->isNavigating();
$inputs->leave(); // Discards the navigation position and saved draft.
```

Each instance keeps its own position and draft in memory; only the input
sequence is persisted and shared. Adapters own keyboard handling and decide
when to leave navigation, such as on editing or submitting input. A web
frontend can use only `entries()` and navigate locally in JavaScript, without
a backend call for each arrow key.

`record()` accepts a Neuron `UserMessage`, including plain text and Command
syntax. Its content blocks and metadata are persisted together, including
image-only and file-only inputs. `entries()` returns `list<UserMessage>`;
`older()` and `newer()` return `?UserMessage`. The draft passed to `older()` is
also a `UserMessage`.

All stored entries use Neuron's serialized user-message representation.
Invalid entries, including plain strings, are rejected. No previous-format
reader or migration is supplied. Consecutive duplicate comparison includes
content and metadata, excluding Neuron's automatically generated message ID.
